# P3.0 - Bounded Fit Validation and Experiment Closure

> Historical plan. Retained for rationale and evidence, not current implementation instructions. Follow the [current specification](../../plans/unified-translator-design.md) and [execution checklist](../../plans/unified-execution.md).

Status: Complete 2026-09-28. Closure report with supported/unresolved cases, evidence and follow-ups: [fit-measurement experiment](../../experiments/fit-measurement/README.md). Revised earlier the same day under owner-approved [ADR-012](../../decisions/ADR-012-lightweight-fit-policy.md), replacing the broad layout-engine/native-parity gate.

## Objective

Close current research, retain useful measurement code and define an honest support boundary. Translation accuracy, preservation and simple fast processing take precedence over exact Office layout matching.

## Required work

1. Inspect the working tree; preserve the other agent's work. Summarize existing Word/PowerPoint evidence, actual/excluded case counts, remaining errors and application/font versions. Unmeasured text boxes are not validated.
2. Audit experimental metrics/multipliers. Retain only rules with a defensible supported scope and representative validation. ADR-012 does not approve universal hhea or East Asian 1.3 rules. Uncertain cases retain original sizes and report unresolved; do not start more font-by-font reverse engineering.
3. Reconcile LayoutSupport, estimator and report with ADR-012. Keep format interpretation in adapters and policy in fit/. Reuse the font manifest; no replacement-engine comparison or provisioning service.
4. Freeze ADR-012's small corpus, reusing existing fixtures. Check saved outputs for content/structure preservation, obvious clipping falsely marked passed, unnecessary shrinking, reflow and missing-font diagnostics.
5. Record fit timing separately from translation using existing instrumentation. Pin strategy/font identity and current defaults; do not invent latency claims.
6. Publish docs/experiments/fit-measurement/README.md with supported cases, unresolved cases, evidence and concrete follow-up defects. Then proceed to P3 integration.

## Exit criteria and stop rule

- Existing findings recorded without claiming universal native parity.
- Small corpus and support boundary explicit; known unreliable cases become unresolved.
- ADR-012 defaults and implementation/report contracts reconciled.
- No more experiments solely to improve line-count/pitch agreement or cosmetic layout. Expand tests only for a concrete preservation, false-pass, excessive-shrink or content-loss defect.
- Missing native acceptance evidence remains pending; continue independent work and never label skipped checks passed.

Production fit work already exists. Do not restart it or require a new measurement ADR. PDF strategy remains P4; general visual review remains P7.
